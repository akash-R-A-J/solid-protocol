## 1. Method

This audit is structured as six independent verification passes, each scoped narrowly, run in parallel, and required to produce file:line evidence for every claim. The matrix is:

| Pass | Question | Evidence form |
|------|----------|----------------|
| A    | Do CLAUDE.md's "hard invariants" still hold byte-for-byte in code? | program ID matches across 3 sources, struct SPACE arithmetic, owner-check sites, public-input index constants, register_issuer subgroup wiring |
| B    | Does the Groth16 public-input contract agree across circuit / program / SDK? | NR_PUBLIC_INPUTS=32, slot indices, Poseidon arities (6/5/2/5), VK pin chain |
| C    | Are cryptographic primitives byte-for-byte identical across solid-core / solid-light / wasm / ts-sdk? | tests/vectors coverage, BJJ coord forms, EdDSA cofactor-8, G2 imag/real swap, schema-hash 5-input, Merkle depth-20 |
| D    | Do every TS SDK helper and every script call the post-Phase-E ix surface? | per-ix caller matrix; bypass / debug flag inventory |
| E    | Do the docs (CLAUDE.md, README, ADRs, audits, plans, registry) agree with the current code state? | line-cited drift list, top-impact ranking |
| F    | What's the test surface and what passes today? | inventory of every test file with status, run results for cargo + npm + vectors |

Plus an empirical pass:
- **Clean-slate localnet e2e** — kill validator, wipe ledger, wipe state.json, fresh `cargo build-sbf`, fresh `solana program deploy`, `npm run e2e` with `SOLID_VOTING_PERIOD_SECONDS=120`. Result captured separately in `plan/INTEGRATION_AND_TEST_STATUS_2026-05-02.md`.

All six pass-reports are self-contained and reproduce here, then synthesised into one drift catalog.

8. **Docs ↔ code.** Drift exists (per §6) but is bounded to README/CURRENT_STATE/IMPLEMENTATION_PLAN/CLAUDE.md placeholders; the registry + canonical audit + RESUME.md are current. PASS-with-fixable-drift.

**No fragmentation.** Every layer has exactly one source of truth (programs and circuits at the bottom, scripts at the top), and consumers reference upward without parallel reimplementations.
